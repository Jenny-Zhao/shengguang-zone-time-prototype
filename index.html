扫码上传示警音频

· 使用手机扫描二维码，在手机端上传示警音频
· 支持 mp3 / wav / m4a，≤ 2MB，时长 ≤ 15 秒
· 二维码 10 分钟内有效，过期后需重新生成
· 上传完成后音频自动关联到当前警示区，机器人下次同步任务配置时生效

原型说明（对照 PRD V3）

入口：设置页 › 语音灯光和动画，新增「声光警示区生效时段」卡片。

能力：按区配置生效时段（按周重复、最多 3 段、支持跨天），与建图 2.0 / PC 建图工具同一份配置，三端互通。

规则：时段外进入区域不播报（含蜂鸣与灯效）；「全天生效」开关等价于未设置时段。

V1.1 新增：每区支持「扫码上传自定义示警音频」——机器人端生成带区 ID 的临时二维码，手机扫码上传（mp3/wav/m4a，≤2MB，≤15s），完成后自动关联该区；未上传或选内置时回退默认音频。

PRD 影响：属性表「生效时段」三端支持列由「新版 / PC」扩为「新版 / PC / 本体设置页」；「示警语音」新增「扫码上传自定义音频」来源，均需回写 PRD。
