原型说明（V1.2）

职责切分：生效时段 + 音频选择 → 建图 2.0 元素属性弹窗（新增两组配置项）；设置页 → 只保留「扫码上传自定义音频」入口。

弹窗新增：① 生效时间（全天生效开关 + 按周时段，最多 3 段，支持跨天）；② 音频选择（勾选警示语音后出现：内置音频库 / 已上传的自定义音频）。

V1.3 调整：设置页「声光警示区自定义音频」卡片点击直接弹出二维码（弹窗内可切换目标警示区，换区换码）。

V1.5 调整：被地图声光警示区元素使用中的自定义音频不可删除——列表中标「使用中」徽标与红色提示，点删除弹提醒「需先在地图中切换为其他语音内容后再删除」；未被使用的音频可直接删除。

V1.6 调整：建图 2.0 属性弹窗移除「警示模式（静音 / 警示）」选择项，弹窗仅保留名称、警示内容、生效时间与音频选择。

V1.7 调整：生效时间固定为「全天生效」，不支持配置时间段（原全天开关与按周时段编辑移除）。

PRD 影响：三、1 建图 2.0 端补两组属性；设置页仅保留音频上传入口；示警语音格式规范（mp3/wav/m4a，≤2MB）待回写 PRD。
