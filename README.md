# 声光警示区 · 生效时段配置原型

PUDU 清洁业务线 · 设置页「语音灯光和动画」新增「声光警示区生效时段」的高保真可交互原型。

**V1.1**：每个示警区新增「示警音频」配置——支持内置音频库 / 扫码上传自定义音频；机器人端生成带区 ID 的临时二维码（10 分钟有效），手机扫码上传 mp3/wav/m4a（≤2MB、≤15s），完成后自动关联该区，未上传时回退内置音频。

## 在线预览

部署到 GitHub Pages 后：`https://<你的用户名>.github.io/shengguang-zone-time-prototype/`

## 原型结构（三层）

| 层级 | 内容 |
|---|---|
| 设置页 | 保留真机现有卡片（音量 / 声音播放间隔 / 清洁时播报语音 / 清洁时播报音乐），底部新增「声光警示区生效时段」入口卡片（带新增角标 + 各区时段摘要） |
| 警示区列表 | 3 个示例区，状态徽标：全天生效 / 按时段 N 段 / 未设置；显示时段摘要，跨天显示「22:00–06:00（次日）」 |
| 单区编辑 | 全天生效开关、周一~周日多选、起止时间选择、跨天自动提示、最多 3 段（到 3 段禁用新增）、修改即保存并下发 |

## 与 PRD 的口径对应（声光警示区 V3）

- 生效时段：按周重复、单区最多 3 段、支持跨天、未设置即全天生效。
- 与建图 2.0 / PC 建图工具为**同一份配置**，三端互通。
- 待回写 PRD：属性表「生效时段」三端支持列由「新版 / PC」扩为「新版 / PC / 本体设置页」。

## 技术说明

- 单文件静态页（`index.html`），无构建、无依赖。
- 设计变量取自真机原型：主色 `#1B62FF`、卡片白底 12px 圆角、背景 `#D9DCE2`。
- 本地打开：双击 `index.html` 即可。

## 内容声明

原型为演示用途，示例数据（收银台警示区 / 入口湿滑警示区 / 广告播报区）均为虚构。
