# 声光警示区 · 生效时段配置原型

PUDU 清洁业务线 · 设置页「语音灯光和动画」新增「声光警示区生效时段」的高保真可交互原型。

**V1.1**：每个示警区新增「示警音频」配置——支持内置音频库 / 扫码上传自定义音频；机器人端生成带区 ID 的临时二维码（10 分钟有效），手机扫码上传 mp3/wav/m4a（≤2MB），未上传时回退内置音频。

**V1.2**：配置职责重新切分——「生效时间」与「音频选择」移入建图工具 2.0 的声光警示区属性弹窗（勾选警示语音后出现音频选择：内置音频库 / 已上传自定义音频）；设置页只保留「扫码上传自定义音频」入口，时段在设置页只读展示。同一页面含两个视图（顶部切换）：本体设置页 / 建图 2.0 属性弹窗（含示意底图，点击地图上的区切换弹窗）。

**V1.3**：设置页「声光警示区自定义音频」卡片点击**直接弹出扫码二维码**；二维码弹窗内可切换目标警示区（换区即换码）；已上传音频的管理（试听 / 重扫 / 删除）收进卡片下方次级入口「查看 / 管理各区已上传音频」。

**V1.4**：入口卡片精简（仅标题 + 一句说明 + 管理入口）；二级页改为**直接展示已上传的自定义音频列表**（文件名、关联警示区、大小、时长、上传时间），支持试听与删除；删除后该区示警回退内置音频；无音频时显示空态引导。

**V1.5**：**使用中的音频禁止删除**——已被地图声光警示区元素选用为播报语音的文件，列表中带「使用中」徽标与红色提示，点击删除弹出提醒「需先在地图中切换为其他语音内容后再删除」；未被选用的音频可直接删除，删除后回退内置音频。

**V1.6**：建图 2.0 属性弹窗移除「警示模式（静音 / 警示）」选择项，弹窗仅保留名称、警示内容（警示语音 / 蜂鸣器 / 警示灯）、生效时间与音频选择。

**V1.7**：生效时间固定为**全天生效**，不支持配置时间段——原「全天生效开关 + 按周时段编辑（最多 3 段、跨天）」整体移除，弹窗中生效时间仅作只读展示。

## 原型结构（三层）

| 层级 | 内容 |
|---|---|
| 设置页 | 保留真机现有卡片（音量 / 声音播放间隔 / 清洁时播报语音 / 清洁时播报音乐），底部新增「声光警示区生效时段」入口卡片（带新增角标 + 各区时段摘要） |
| 警示区列表 | 3 个示例区，状态徽标：全天生效 / 按时段 N 段 / 未设置；显示时段摘要，跨天显示「22:00–06:00（次日）」 |
| 单区编辑 | 全天生效开关、周一~周日多选、起止时间选择、跨天自动提示、最多 3 段（到 3 段禁用新增）、修改即保存并下发 |

## 与 PRD 的口径对应（声光警示区 V3）

- 生效时段：按周重复、单区最多 3 段、支持跨天、未设置即全天生效。
- 与建图 2.0 / PC 建图工具为**同一份配置**，三端互通。
- 待回写 PRD：属性表「生效时段」三端支持列由「新版 / PC」扩为「新版 / PC / 本体设置页」。

## 技术说明

- 单文件静态页（`index.html`），无构建、无依赖。
- 设计变量取自真机原型：主色 `#1B62FF`、卡片白底 12px 圆角、背景 `#D9DCE2`。
- 本地打开：双击 `index.html` 即可。

## 内容声明

原型为演示用途，示例数据（收银台警示区 / 入口湿滑警示区 / 广告播报区）均为虚构。
